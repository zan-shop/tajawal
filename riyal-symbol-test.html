✅ Implementation Complete

The Saudi Riyal symbol has been successfully added to the Tajawal font family. This symbol (U+20C1) was officially added to Unicode 17.0 in September 2025.

SAMA Usage Guidelines:

  1. Position: Symbol is ALWAYS to the LEFT of the numeral (all languages)
  2. Spacing: Leave a space between the symbol and numeral
  3. Written Value: Symbol is to the left of written text values
  4. Negative Values: Symbol is to the left of the minus sign and numeral
  5. Proportions: Maintain the geometric structure of the symbol
  6. Geometry: Do not distort or modify the symbol design
  7. Alignment: Symbol height should match text height
  8. Direction: Symbol direction matches text direction
  9. Clear Space: Maintain 1/3 of symbol height as clear space around it
  10. Contrast: Ensure sufficient color contrast with background
